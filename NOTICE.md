# MeshStar Android

Based on permissionlesstech/bitchat-android, upstream commit `14ab73c`.
The upstream history and GPL-3.0 license are retained (see LICENSE).
MeshStar additions use the same GPL-3.0 license. Package names and BLE wire
protocols remain compatible with upstream; the install ID is `net.meshstar.app`.
No MeshStar service endpoint or deployment credential is bundled.
