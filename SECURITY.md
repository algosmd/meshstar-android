# Security policy

Report suspected vulnerabilities privately to **security@meshstar.net**.
Include the affected version, platform, impact, and minimal reproduction steps.
Use synthetic data. Do not include private keys, passwords, tokens, personal
messages, or identifying device logs in a public issue.

Please allow coordinated investigation before public disclosure. Reporters
should test only systems and devices they own or have permission to assess.
This contact does not imply a bug bounty or a guaranteed response deadline.

Use the latest supported release. Security fixes and affected versions will be
identified in release notes when available.
