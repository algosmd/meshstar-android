# M10 P1.2 — repeater administration

Version 0.4.0, stage 3, Android versionCode 11.

## Implemented

- Searchable node list; repeater/room entry opens administration.
- Login success/failure and read-only handling; only successfully authenticated
  credentials are stored, encrypted by the existing Android Keystore storage,
  under the full repeater public key. Forget removes the encrypted credential.
- Time, clock sync, firmware, neighbors, status statistics, radio presets/custom,
  name, advert, confirmed reboot and free-form CLI. Mutations require confirmation.
- CLI replies are CONTACT_MSG_RECV, isolated from chat/history/notifications even
  after the admin screen closes. Password echoes and sensitive command results
  are redacted; bounded console history remains in memory only.
- RF wait is independent of the UART queue. Auto uses the firmware timeout and
  hop count with a 60-second flood floor and 300-second cap; manual 60/120/300
  choices match the later iOS implementation rather than the initial 20-second spec.
- Leaving/backgrounding closes the session and submits logout. Reboot ACK is
  labelled submitted, not proof that the remote repeater has restarted.
- Five translated interfaces with shared controls.

## Validation

- Debug and instrumentation APK builds passed.
- MeshCore JVM: 19 tests, zero failures/errors. Includes key-prefix matching,
  wrong password, read-only login, timeout, successful credential persistence,
  password echo redaction, late CLI isolation, close/logout and status bounds.
- Synthetic API 26 large-screen locale/theme matrix passed, including admin.
  Screenshots and raw logs remain local; no real credentials or coordinates used.
- Physical acceptance is **partial**, as detailed below. No on-radio acceptance
  is claimed from mock tests.

## Physical acceptance — 2026-11-15

On the updated code 13, the user confirmed successful login to the authorized
test repeater, time and firmware replies in the console, and a separate status
card. Radio changes/readback, reboot/restore, password remember/forget, incorrect
password, late-reply isolation and distant-path timeout are not yet confirmed.
