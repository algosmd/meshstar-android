# M10 P1.4 — node map

Version 0.4.0, stage 5, Android versionCode 13. Branch `codex/m10-lora`.
Codes 9–13 follow the existing A6 code 8 without uninstalling user data.

## Implemented

- LoRa map uses OpenStreetMap raster tiles, without a Google Maps key.
- Newest advert per public key, invalid/hidden coordinates excluded; markers
  distinguish companion, repeater, room and sensor. Old adverts fade and turn
  grey. Type and age filters, fit, pan, zoom and accessible node list.
- Marker/list selection opens the P1.3 node card with path actions.
- Companion position comes from its advert/settings. Phone position is requested
  only by the map button, with explicit permission; no last-known location read,
  persistence or background subscription. Leaving/backgrounding removes the
  listener and clears the phone marker.
- Visible viewport tiles only, bounded concurrent requests and response sizes,
  HTTP cache, application User-Agent and visible OSM attribution. Tile requests
  contain no node keys, passwords, tokens or contact records. Like any tile map,
  requested tile coordinates necessarily identify the viewed map area.
- Five translated interfaces, shared compact rectangular controls.
- Final integration also preserves old read markers when migrating case-sensitive
  hashtag names, localizes advert dates, and aligns repeater clock commands with
  the accepted iOS client (`clock`, `clock sync`).

## Validation

- Debug universal and ABI APKs built. JVM suite: app 899 tests, zero failures or
  errors, three existing skips; MeshCore 28 tests; RNSLite 22 tests.
- Model tests cover latest-advert replacement including hidden positions,
  type/age filtering, projection/panning and dateline fit. Tile request test
  checks host, application identification and absence of user credentials.
- Isolated API 26 instrumentation: seven tests on a 320 dp viewport, plus the
  screen matrix on a 427 dp viewport. Five screens × five languages × two themes
  × two widths = 100 local screenshots. Final widths were verified after
  accounting for the emulator's display-size clamp. These are the authoritative
  small/large captures for all five M10 stages.
- All screenshots use synthetic nodes/coordinates. Map networking is disabled
  in the fixture renderer; no real phone location, tiles, messages or identifiers
  were inspected or included. Tile availability and physical map interactions
  remain live acceptance items.
- Lint ran after completing missing dependency-lock configurations. It reports
  repository-wide translation/permission and other issues and is configured not
  to fail the build. A successful lint task is not a clean-lint claim. The new
  map implementation has no reported lint errors; raw output stays local.
- Physical acceptance remains pending: P1.0 APK is installed for channel testing;
  later stages must be tested with the companion and an authorized repeater.
  Automated results do not substitute for these checks.
